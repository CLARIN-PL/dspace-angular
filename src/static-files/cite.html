Good research practice

How to cite resources

Citing data credits its creators, makes research reproducible and directs readers to the exact version of a resource.

Data citation policy

CLARIN endorses the Data Citation Principles, and so does CLARIN-PL. Users must acknowledge and correctly cite data sources in every publication and research output. We also implement the key recommendations of the RDA Data Citation Working Group.

Handle — a persistent identifier

The Handle System assigns unique and persistent identifiers to digital objects. Every published repository resource receives a permanent URL that continues to identify its record even if the underlying infrastructure changes. Always use that Handle in publications instead of a temporary search or download URL.

Template: Creator(s). (Year). Resource title (version). CLARIN-PL Language Resources Repository. https://hdl.handle.net/…

Export formats

The citation box on an item page provides a recommended citation and an export in BibTeX. When several versions exist, cite the version actually used. If the record identifies a related publication that should be cited, include it in addition to the dataset citation.
