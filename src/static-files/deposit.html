For depositors

How to deposit a resource

Deposit is free of charge. This guide follows the current CLARIN-PL submission process, from preparing a resource to editorial review and publication. The precise metadata screens may vary by collection.

Before you begin

Prepare the resource files and documentation, a clear title and description, creators and affiliations, language, version, sources and funding details. Check that you have the right to deposit every file and to grant the proposed distribution licence. Prefer well-documented, open formats where possible and consult the CLARIN-PL format recommendations in the Standards Information System.

  1. 01 / Account

    Sign in

    Use the sign-in option offered on the repository page: institutional federated login or an agreed local account. Only authenticated users can start a deposit. If your organisation is unavailable or sign-in fails, contact dspace@clarin-pl.eu.

  2. 02 / Collection

    Start a submission

    Open My DSpace, start a new submission and choose the appropriate collection. Your unfinished submission can be saved and resumed later. If you are unsure which collection to use, ask the help desk before submitting.

  3. 03 / Type

    Identify the resource

    If the form asks, choose the resource type (for example, a corpus, lexical resource or tool). Enter the title and any existing identifiers. The repository assigns its own persistent identifier after approval; do not enter a future Handle as an existing identifier.

  4. 04 / Description

    Complete the metadata

    Describe the people, organisations and projects involved, then provide a useful abstract, language, keywords, version, sources and links to related publications or resources. Complete all required fields. Depending on the collection, the description is divided into two or three screens.

  5. 05 / Files

    Upload and document files

    Add the resource, a README, usage instructions and any relevant code or schemas. Give files meaningful names and descriptions. A file is not mandatory for every type of record, but a data deposit should include the materials needed to understand and reuse it.

  6. 06 / Rights

    Accept the deposit terms and select a licence

    Read and accept the deposit agreement, which confirms your authority to submit the resource. Then choose a distribution licence for users, either directly from the list or with the licence selector. These are two distinct steps. If no offered licence fits your rights situation, contact the help desk before completing the submission.

  7. 07 / Notes

    Add a note for editors if needed

    The final metadata section lets you leave a note for reviewers and link a resource that this version replaces. Explain anything the editorial team should check, such as a new version or special rights conditions.

  8. 08 / Send

    Check and complete the submission

    Review the information and files in the submission form, correct any validation errors and complete the submission. You can save an unfinished draft instead. The former separate “Review” screen shown in older guides is not a step in the current configured process.

  9. 09 / Publication

    Respond to editorial feedback

    Editors check metadata quality, technical documentation, files, rights and the licence. They may ask for corrections before approval. Once accepted, the record becomes visible according to the agreed access conditions and receives a persistent Handle to use when citing the resource.

Restricted access or an embargo?

Contact dspace@clarin-pl.eu before submitting. The current form does not offer a separate self-service embargo or item access step; restrictions require an arrangement with the repository team.

After publication

For metadata corrections, a new version, changed access conditions or withdrawal, contact the help desk. Significant changes to data are managed as a new linked version so the previous record remains identifiable.
